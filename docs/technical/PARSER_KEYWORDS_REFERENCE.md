## ⚙️ Правила добавления ключевых слов

### 1. Все слова в нижнем регистре

```python
# ✅ Правильно
ADDRESS_KEYWORDS = ["улица", "ул", "ул."]

# ❌ Неправильно
ADDRESS_KEYWORDS = ["Улица", "УЛ", "Ул."]
```

**Причина:** Проверка идет через `text.lower()`

### 2. Добавляйте полное название + сокращения

```python
# ✅ Правильно (все варианты)
"бульвар", "б-р",

# ⚠️ Неполно (нет полного названия)
"б-р",
```

### 3. Точки как отдельные варианты

```python
# ✅ Правильно (с точкой и без)
"ул", "ул.",
"д", "д.",

# ❌ Неправильно (только один вариант)
"ул.",
```

### 4. Добавляйте комментарий для категории

```python
ADDRESS_KEYWORDS = [
    # ... предыдущие слова ...

    # Новая категория (например, посёлки)
    "посёлок",
    "пос",
    "пос.",

    # ... следующие слова ...
]
```

## 🚫 Слова-индикаторы проблемы

**Файл:** `app/services/telegram_parser/patterns.py:285`

### Текущий список

```python
problem_indicators = [
    "не",
    "течёт",
    "течет",
    "шумит",
    "крутит",
    "работает",
    "включается",
    "выключается"
]
```

### Правила

1. **Все слова в нижнем регистре**
2. **Проверка по границам слов** (`\b`) — "не" в слове "Нефтяников" НЕ считается
3. **Добавляйте варианты с ё и е** — `течёт` и `течет`

### Как добавить новое слово

```python
problem_indicators = [
    "не",
    "течёт", "течет",
    "шумит",
    "крутит",
    "работает",
    "включается",
    "выключается",
    "сломался",     # НОВОЕ
    "сломалась",    # НОВОЕ
    "барахлит",     # НОВОЕ
]
```

### Тест списка адресов

```bash
source venv/bin/activate
python3 -c "
from app.services.telegram_parser.patterns import looks_like_address

test_cases = [
    'ул. Ленина 5',
    'микрорайон Солнечный 25',
```
