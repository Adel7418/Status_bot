# 🤖 Telegram Bot - Система управления заявками на ремонт техники

Telegram-бот для автоматизации процесса приема, обработки и выполнения заявок на ремонт бытовой техники.

## 📋 Описание

Система предназначена для управления заявками на ремонт техники с поддержкой нескольких ролей пользователей:
- **Администраторы** - полный доступ к системе, управление пользователями и мастерами
- **Диспетчеры** - создание заявок, назначение мастеров, управление статусами
- **Мастера** - просмотр назначенных заявок, обновление статусов выполнения

## 🚀 Быстрый старт

### Для новых пользователей
👉 **[docs/project/START_HERE.txt](docs/project/START_HERE.txt)** - Начните отсюда!

### Вариант 1: Makefile (Рекомендуется) ⭐

```bash
# Локальная разработка (без Docker)
make install-dev    # Установить зависимости
make run            # Запустить бота

# Docker (dev режим на локальной машине)
make dev-start      # 🚀 Запустить dev бота
make dev-logs       # 📋 Смотреть логи
make dev-stop       # Остановить

# Multibot (два бота + Redis)
make mb-prepare     # Создать директории
make mb-start       # 🚀 Запустить оба бота
make mb-logs-city1  # Логи city1
make mb-logs-city2  # Логи city2

# Все доступные команды
make help           # Показать полный список команд
```

### Вариант 2: Ручная установка

<details>
<summary>Развернуть инструкцию</summary>

```bash
# 1. Создайте виртуальное окружение
python -m venv venv

# или

# 2. Установите зависимости
pip install -r requirements-dev.txt

# 3. Настройте .env
cp env.example .env
nano .env  # Заполните BOT_TOKEN, ADMIN_IDS,

# 4. Запустите бота
python bot.py
```

## 🚀 Технический стек

- **Python** 3.11+
- **aiogram** 3.16.0 - асинхронный фреймворк для Telegram Bot API
- **SQLite** + aiosqlite - база данных
- **APScheduler** 3.11.0 - планировщик задач
- **openpyxl** 3.1.5 - генерация Excel отчетов
- **pydantic** 2.10.3 - валидация данных
- **telethon** 1.34.0 - парсер заявок из Telegram группы
- **Docker** - контейнеризация
- **Alembic** - миграции БД
- **pytest** - тестирование
